# Playbook — Onboard a New Host

**Goal:** a verified host running their second event within 30 days, with quality ≥ 4.5/5 attendee feedback. **Lead owner:** Host_Success (COM-HS).

---

## Step 1 — Application & Vetting (Day 0–3)
| # | Action | Owner | Ticket |
|---|---|---|---|
| 1 | Application: proposed activity, cadence, venue, group size | Applicant → User_Support | SUPPORT |
| 2 | Identity + affiliation check (student ID / org membership where applicable) | COM-HS | TASK |
| 3 | Safety screening: policy quiz (buddy system, group-only, no 1-on-1 defaults, alcohol rules, incident protocol) | TS-POL provides quiz | TASK |
| 4 | Video/voice call: vibe check, facilitation skill, first-20-minutes plan | COM-HS + Campus_City_CM | TASK |
| 5 | Veto check: T&S pattern screen (any prior reports) | TS-INV | TASK |

**Any T&S or Legal veto = application closed with polite generic response. Reasons logged (Action_Log).**

## Step 2 — Activation (Day 3–10)
6. Host toolkit: facilitation guide per activity type (outdoor vs indoor scripts), check-in procedure, emergency contacts, what-to-do-if report.
7. First event co-hosted or shadowed by an experienced host (Stage 1+); Stage 0: Campus_City_CM attends.
8. First event instrumented: attendance rate, feedback form, arrival friction notes.

## Step 3 — Verification & Loop (Day 10–30)
9. Verified badge granted after first successful event (attendance ≥60%, no safety flags, feedback ≥4.0).
10. 30-day check: second event held? streak alive? If not → Host_Success re-engagement playbook (personal message, co-host offer).
11. Quarterly: host quality review — activation rate, feedback trend, report history. Underperforming hosts get training; unsafe hosts are suspended via T&S path.

## Metrics
Host activation >60% · median time-to-second-event <30 days · host-attributed safety reports <1% of events.

## Notes
- Hosts are supply, but **quality-filtered supply**. A bad host costs more than no host (P4).
- Every host interaction (messages, calls, suspensions) is logged — Work_History/Action_Log under COM-HS.
