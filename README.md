# Squad_Company — Multi-Agent Organizational System

A complete markdown-based operating system for a group of agents (or a student founder wearing many hats) building **Squad**: an activity-first, IRL-connection platform for Gen Z — a bridge, not a destination.

## Start Here
1. Read `00_Company_Core/Onboarding.md` (2-hour onboarding path).
2. Then `00_Company_Core/Company_Strategy.md` → `Core_Principles.md` → `Shared_Metrics.md`.
3. Find your role in `00_Company_Core/Agent_Registry.md`.

## Structure
| Path | Contents |
|---|---|
| `00_Company_Core/` | Strategy, principles, metrics, decision framework, rituals, dependency map, communication protocols, agent registry, onboarding, stage config, escalation matrix, knowledge base, playbooks, templates, ticket system, work history (CRM) |
| `01_Product/` … `10_Business_Finance_Ops/` | 10 departments, each with goals, decision-making rules, and per-role Skills.md + Decision_Authority.md written in expert personas |
| `11_Leadership/` | CEO_Founder, COO, Executive_Sync |

## Operating Laws (short version)
- P1–P10 in Core_Principles.md are veto law. Safety (T&S) and Legal hold standing vetoes.
- If it matters → ticket. If decided → Decision Record. If done → Action Log. Chat is coordination only.
- Density beats features: no expansion while attendance < 70% in the current campus.
- Measure the real world (verified attendance & return), never screen time.

*Built from the Squad founding context (2026). Personas are decision heuristics, not impersonations.*
