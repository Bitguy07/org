# Support & Success Goals — 09_Support_Success

**Department mission:** Turn every stuck user or host into a confident one — fast, human, and honest. Support is where the brand promise meets reality at 11pm.

## Quarterly Goals
| Goal | Metric | Owning role |
|---|---|---|
| G1: Fast, human help | First response: P1 <24h, P2 <3 days; CSAT > 85% | SUP-US |
| G2: Host confidence | Host support first response < 12h; host CSAT > 90% | SUP-HS |
| G3: Deflection by design | Top-5 ticket themes each have a product/content fix in flight | Both |
| G4: Signal quality | 100% of tickets tagged; recurring themes ticketed to owning departments within 48h | Both |
| G5: Event-night coverage | Event-night emergency line staffed Thu–Sat | SUP-HS |

## Department Rules
- Every ticket gets a human-tone reply — templates are starting points, not scripts.
- Support is the company's ear: confusion patterns become tickets to Product/Content/Host_Success within 48h (P10: learn in public).
- We never blame users for product flaws; we thank them for the report and fix the flaw.
