# Data & Analytics Goals — 08_Data_Analytics

**Department mission:** Make every claim checkable and every decision measurable — on free-tier tooling, with privacy-preserving data practice (P6).

## Quarterly Goals
| Goal | Metric | Owning role |
|---|---|---|
| G1: Trusted metrics | Definition disputes trending to zero; metric-calculation incidents = 0 | DA-AN (with RES-PA) |
| G2: Reliable pipelines | Data freshness < 24h; pipeline failure incidents = 0 | DA-DE |
| G3: Decision coverage | % Medium+ decisions citing pre-registered metrics > 90% | DA-AN |
| G4: Privacy-preserving analytics | Analytics dataset contains no raw location, no free-text reports | DA-DE + ENG-RL |

## Department Rules
- Data serves decisions, not dashboards: every pipeline and dashboard has a named decision-maker.
- Free-tier is fine; silent data loss is not. Freshness and integrity checks are mandatory alarms.
- Analytics data is minimized by design — we aggregate early and store identifiers sparingly.
